# rakuten-items-to-sheet

楽天市場の決めた商品の価格・在庫を API で取得し、前回からの値動きを付けて Google スプレッドシートに保存するツールです。
在庫管理や価格調整のための「商品データの記録」のプロトタイプです。

## 何をするものか

`python main.py` を実行すると、`items.txt` に書いた商品ごとに次のことをします。

1. 楽天市場 商品検索 API から、商品名・ショップ・価格・在庫・レビュー件数・平均点を取得する
2. 前回の価格と比べて、差額と値動き（初回／値上がり／値下がり／変わらず）を付ける
3. スプレッドシートに書く
   - **最新**シート：商品1つにつき1行。毎回書き直す（今の状態がひと目で分かる）
   - **履歴**シート：実行するたびに下へ追加する（あとで値動きを分析できる）

```
$ python main.py
商品 5 件のデータを楽天から取得します…
  1/5 水筒 730ml 1L 1.5L ステンレス 直飲み ワンタ … 1,780円（前回と同じ）在庫あり
  2/5 voda ステンレス スポーツジャグ 2000/2L/2リッ … 2,980円（前回と同じ）売り切れ
  ...
スプレッドシートに保存しました（最新：5行／履歴：5行を追加）
```

楽天の Web ページのスクレイピングはせず、公式の API だけを使います。

## 事前準備

- Python 3（Anaconda で動作確認）
- ライブラリ：`requests`、`python-dotenv`、`gspread`、`google-auth`
  ```
  pip install requests python-dotenv gspread google-auth
  ```

## 秘密ファイルの用意の仕方

鍵が入るので、`.env` と `service_account.json` は GitHub に載せません（`.gitignore` に書いてあります）。

### 1. 楽天のアプリ ID とアクセスキー（`.env`）

1. [楽天ウェブサービス](https://webservice.rakuten.co.jp/) にログインし、「アプリID発行」を押す
2. 次のように登録する
   - アプリケーション名：英数字だけ（ハイフンなどの記号は使えない）
   - アプリケーションタイプ：**Web Application**
   - 許可された Web サイト：`github.com`
   - API アクセススコープ：楽天市場 API
3. `.env.example` をコピーして `.env` を作り、アプリ ID と **アクセスキー** を貼る（すぐ近くに出る「アフィリエイト ID」と間違えない）

> このプログラムは、楽天に「github.com から来た」という印（`Origin`・`Referer`）を付けて頼みます。
> 自分の GitHub のリポジトリで使うときは、`main.py` の先頭の `APP_SITE_URL` を自分のリポジトリの URL に変えてください。

### 2. Google のサービスアカウント（`service_account.json`）

1. Google Cloud Console で Google Sheets API を有効にし、サービスアカウントを作って鍵（JSON）をダウンロードする
2. `service_account.json` という名前で `main.py` と同じフォルダに置く
3. スプレッドシートを新しく作り、サービスアカウントのメールアドレス（JSON の `client_email`）に「編集者」で共有する
4. シートの URL を `.env` の `SPREADSHEET_ID=` に貼る（URL 全体でも ID だけでもよい）

## 使い方

### 管理する商品を決める

楽天の商品コード（`お店:番号`）を `items.txt` に1行ずつ書きます。商品ページの URL の中の名前とは違うので、次のコマンドで探します。

```
python main.py --search 水筒 ステンレス
```

```
 1. livingut:10020902               1,780円 在庫あり  水筒 730ml 1L 1.5L ステンレス 直飲み ワンタ
    https://item.rakuten.co.jp/livingut/4903779704932/
```

URL を Cmd ＋ クリックすると、ブラウザで画像や詳細を見られます。決めた商品の商品コードを `items.txt` に貼ります（`#` から後ろはメモ）。

```
livingut:10020902        # 水筒 730ml ステンレス
```

### 取得して保存する

```
python main.py
```

最後に表示される URL でスプレッドシートを開けます。最初の実行で「最新」「履歴」シートが作られます。

## ファイル

| ファイル | 中身 |
|---|---|
| `main.py` | プログラム本体（設定はファイルの先頭にまとめてある） |
| `items.txt` | 管理する商品の商品コード |
| `.env.example` | `.env` の書き方の見本 |
| `要件定義書.md` | 作る前に決めたこと・その理由・受け入れテスト |
